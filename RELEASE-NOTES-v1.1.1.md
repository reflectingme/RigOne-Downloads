# RigOne v1.1.1

RigOne v1.1.1 refines the new Hamlib support added in v1.1.0.

## Highlights

- Added a searchable Hamlib radio model picker.
- Saved the selected Hamlib model and showed the active connection type more clearly in the app.
- Kept direct IC-7300 support available for frequency, mode, PTT, audio mute/live, S-meter, panadapter, and waterfall functionality.
- Kept unsupported Hamlib-only features disabled or hidden where the selected radio path does not provide them.

## Hamlib Status

Hamlib support has currently been tested with an Icom IC-7300 only.

Feedback from operators using other Hamlib-supported radios is very welcome, especially around frequency control, mode changes, PTT, audio mute/live behaviour, and S-meter reporting.

Panadapter and waterfall display are only available in RigOne's direct IC-7300 mode where live scope frames are available.

## Install

Download and run:

```text
RigOne-Setup-v1.1.1.exe
```
